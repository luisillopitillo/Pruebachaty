# DESERT RUN

Juego 3D de supervivencia y conducción para navegador.

## Cómo jugar
- WASD: moverte a pie o conducir.
- SHIFT: correr.
- E: recoger objetos, entrar o salir del todoterreno.
- R: arrancar o apagar el motor.
- Encuentra las 3 piezas repartidas por el desierto.
- Repara el vehículo, recoge bidones de combustible y conduce hasta LAST STOP.

En móvil aparecen controles táctiles. Usa Three.js desde CDN y no necesita instalación.

## Ejecutar
Abre index.html desde un servidor estático o publícalo con GitHub Pages.
